## Limits of this inventory

The rows establish what the Python asks, compares and attempts. They do not establish Salesforce automation effects, email delivery, Notion task existence, completeness of history tracking, current permissions, duplicate-rule configuration, or transaction outcomes after a timeout. Existing repository documents describe earlier investigation and external evidence; those claims were not treated as fresh verification here.

A useful learning exercise is to compare `return`, `continue`, and `raise` in `_finish_batch`, `_provision_missing_participant_users`, and `review`: each sends execution to a different place, which explains several partial-processing outcomes.
